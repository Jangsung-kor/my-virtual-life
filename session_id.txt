[2. 에이전트 권한 체계 (Agent Permissions & Security)]
================================================================================

Antigravity 에이전트는 전역(Global) 설정 및 프로젝트별(Project-level) 설정을
통해 권한과 보안 경계를 유연하게 통제할 수 있습니다.

1) 도구 및 터미널 실행 정책 (Tool Execution Policy)
   - always-proceed     : 명령어나 도구 실행 시 별도 확인 없이 즉시 실행
   - request-review     : 터미널 명령어 실행 전 사용자의 명시적 승인을 요청
   - strict             : 위험 가능성이 있는 작업에 대해 엄격히 차단 또는 검토 요구
   - proceed-in-sandbox : 터미널 샌드박스 내부에서만 자동 실행 허용

2) 파일 접근 권한 (File Access Policy)
   - 워크스페이스 내부  : 기본적으로 읽기, 파일 생성, 부분 수정(Edit) 권한 보유
   - 워크스페이스 외부  : Non-Workspace File Access 설정에 따라 동작
     * allow : 외부 파일도 자유롭게 읽기/쓰기 허용
     * ask   : 외부 파일 접근 시 사용자 확인 팝업
     * deny  : 워크스페이스 외부 파일 접근 완전 차단

3) 터미널 샌드박스 (Terminal Sandbox Mode)
   - 활성화 시 가상화/격리된 샌드박스 컨테이너 안에서 명령어가 실행되어
     로컬 머신의 파일시스템 및 민감 환경에 영향을 주지 않도록 보호합니다.

4) 네트워크 및 브라우저 정책 (Internet Access & Browser Policy)
   - 인터넷 접근 (allow / ask / deny) : 에이전트의 외부 웹 요청 가능 여부 제어
   - 브라우저 화이트리스트 (Browser Allowlist) : 웹 자동화/브라우징 시 허용할 도메인 지정

5) 허용/차단 목록 (Allowlist & Denylist)
   - Command Allowlist / Denylist : 항상 허용할 명령어 또는 절대 실행 불가한 명령어를 지정
   - Permission Grants : 특정 파일, 디렉터리, URL에 대한 권한 규칙을 전역/프로젝트 단위로 정의

6) 아티팩트 리뷰 모드 (Artifact Review Mode)
   - always-proceed : 아티팩트 생성 시 사용자 검토 대기 없이 진행
   - agent-decides  : 에이전트 판단에 따라 피드백 요청 여부 결정
   - asks-for-review: 중요한 계획/변경 사항이 포함된 아티팩트에 대해 사용자 승인 요청

7) 보안 수칙 및 금지 행위 (Absolute Security Rules)
   - 접근 제어, 권한 검사, 샌드박스 격리 경계 우회 행위 금지
   - 자격 증명 탈취 및 비인가 호스트 서비스 프로빙 금지
   - CAPTCHA, Turnstile, Altcha 등 봇 감지/작업증명 게이트 우회 시도 금지
